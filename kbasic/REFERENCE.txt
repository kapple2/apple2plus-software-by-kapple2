2. 애플소프트 오류 메시지
-------------------------

오류 줄은 "?" + 한글 문구 + " 오류" 모양입니다. 오류번호(PEEK(222))와 ONERR는
영어 때와 같습니다. 글자만 바뀝니다.

+------------------------+--------------+------------------------------------------------+
| 영어                   | 한글         | 설명 (끝의 수는 오류번호 PEEK(222))            |
+------------------------+--------------+------------------------------------------------+
| NEXT WITHOUT FOR       | FOR 없음     | NEXT에 짝이 되는 FOR가 없습니다. 오류번호 0.   |
| SYNTAX                 | 문법         | 문장 모양이 틀렸습니다. 16.                    |
| RETURN WITHOUT GOSUB   | GOSUB 없음   | RETURN에 짝이 되는 GOSUB가 없습니다. 22.       |
| OUT OF DATA            | 자료끝       | READ할 DATA가 더 없습니다. 42.                 |
| ILLEGAL QUANTITY       | 범위         | 수가 허용 범위 밖입니다(음수 첨자, 큰 좌표     |
|                        |              | 등). 53.                                       |
| OVERFLOW               | 넘침         | 계산 결과가 너무 큽니다. 69.                   |
| OUT OF MEMORY          | 메모리부족   | 프로그램이나 변수가 메모리에 안 들어갑니다.    |
|                        |              | 77.                                            |
| UNDEF'D STATEMENT      | 줄없음       | GOTO, GOSUB 등이 가리키는 줄이 없습니다. 90.   |
| BAD SUBSCRIPT          | 첨자         | 배열 첨자가 선언한 크기를 벗어났습니다. 107.   |
| REDIM'D ARRAY          | 배열중복     | 같은 배열을 두 번 DIM했습니다. 120.            |
| DIVISION BY ZERO       | 0으로 나눔   | 0으로 나누었습니다. 133.                       |
| ILLEGAL DIRECT         | 직접불가     | 직접 입력으로는 쓸 수 없는 문장입니다(INPUT,   |
|                        |              | GET, DEF 등). 149.                             |
| TYPE MISMATCH          | 형식다름     | 수와 문자열을 잘못 섞었습니다. 163.            |
| STRING TOO LONG        | 문자열 김    | 문자열이 255글자를 넘습니다. 176.              |
| FORMULA TOO COMPLEX    | 식 복잡      | 식이 너무 복잡합니다. 191.                     |
| CAN'T CONTINUE         | 계속불가     | CONT로 이을 수 없습니다. 210.                  |
| UNDEF'D FUNCTION       | 없는 함수    | 정의하지 않은 FN을 불렀습니다. 224.            |

참고
----
- 메시지는 K-HANGEUL 드라이버(v1.5 이상)가 한글로 바꿉니다.
- PR#0 뒤나 드라이버를 거치지 않는 출력은 영어로 나옵니다.
- 128K가 아닌 Saturn 카드에서는 DOS와 애플소프트 메시지가 영어입니다.
- 모니터, 정수 BASIC, ProDOS의 메시지는 영어입니다.
