이것은 애플 II용 부루마블 보드 게임입니다. 혼자서 플레이할 수도 있고, 최대 4명까지 함께 즐길 수 있습니다. (사람 1명, 컴퓨터 3명)

This is the Blue Marble board game for the Apple II. It supports single-player mode and can accommodate up to 4 players (1 human player and 3 computer players).
