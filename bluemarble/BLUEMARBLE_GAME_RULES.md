# 부루마불 (Blue Marble) — Apple II 버전 게임 규칙

상태: Goal 1 초안, 검토용.

이 문서의 금액 단위는 원입니다. `1만` = 10,000원. 코드에서는 1 단위 = 1,000원으로 둡니다 (DOS 게임도 같은 방식).

| 주사위 | **2개** (합만큼 이동, 더블이면 한 번 더 굴림). 블로그 구성품 목록은 1개라고 하지만 같은 블로그의 규칙 설명과 위키는 2개 |

## 2. 주사위와 턴

1. 시계 방향으로 돌아가며 진행합니다. 사람이 1번 플레이어입니다.
2. 주사위 2개를 굴려 합만큼 시계 방향으로 이동합니다.
3. 두 주사위가 같은 눈(더블)이면 칸 처리 후 한 번 더 굴립니다. 더블이 몇 번 연속되어도 제한이 없습니다 (DOS 코드 확인: 3연속 더블 규칙 없음). 단, 무인도나 우주정거장에 들어가면 더블이어도 더 굴리지 못하고, 파산하거나 후반전이 시작될 때도 턴이 끝납니다.
4. 출발을 지나가거나 정확히 멈추면 은행에서 월급 20만원을 받습니다.
5. 도착한 칸을 처리합니다 (4절).

## 4. 칸별 규칙

**주인 없는 도시/특수 땅.** 가격을 내고 살 수 있습니다. 사지 않으면 아무 일도 없습니다 (경매 없음. 실제 게임에는 경매가 있지만 Apple II 버전은 메모리 절약을 위해 뺍니다).

**남의 땅.** 주인에게 통행료를 냅니다. 건물이 없으면 대지료, 건물이 있으면 지어진 건물 각각의 통행료를 모두 더한 금액입니다 (대지료는 더하지 않음. 7절, DOS 코드 확인). 예외: 우대권을 가지고 있고 사용하기로 한 경우. 주인이 무인도에 있어도 통행료는 받습니다.

**내 땅.** 건물을 지을 수 있습니다 (7절). 건축은 **후반전**에만 가능합니다. 후반전은 땅이 24개(전체 29개 중 5개 남음) 팔리면 시작하고(DOS는 28개 중 25개), 그 전이라도 30라운드가 지나면 시작합니다. 후반전이 시작되면 모든 플레이어가 출발로 돌아갑니다 (월급 없음, 무인도와 우주여행 상태 해제).

**황금열쇠.** 맨 위 카드를 뽑아 처리하고 맨 아래에 넣습니다. 예외: 보유형 카드는 사용할 때까지 가지고 있습니다 (6절).

**무인도 (10).** 멈추면 갇힙니다 (그 턴은 끝). 이후 매 턴 주사위를 굴려 더블이 나오면 즉시 탈출하고 그 눈만큼 이동합니다 (더 굴리지는 않음). 더블이 없으면 두 턴을 쉬고, **세 번째 턴에는 더블이 아니어도 나가서** 그 눈만큼 이동합니다. 무인도 탈출 카드가 있으면 카드를 쓰고 바로 굴려 이동할 수 있습니다. 돈을 내고 나오는 방법은 없습니다. 무인도에 멈추지 않고 지나가기만 하면 아무 일도 없습니다.

**사회복지기금 (38).** 기금에 15만원을 냅니다. 기금은 모든 플레이어의 납부액이 쌓입니다.

**사회복지기금 접수처 (20).** 쌓인 기금 전부를 받습니다. 비어 있으면 아무 일도 없습니다.

**우주여행 (30).** 우주정거장으로 갑니다. 컬럼비아호 주인에게 20만원을 냅니다. 주인이 없으면 은행에 냅니다 (DOS와 Java 모두 이렇게 하며, 블로그의 "주인이 없으면 무료"와 다름). 20만원이 없으면 가지 못하고 그냥 지나갑니다. 다음 턴에는 주사위를 굴리지 않고 원하는 칸을 골라 이동합니다. 이 이동 중 출발을 지나면 월급을 받습니다.

**출발 (0).** 지나가거나 멈추면 월급 20만원.

**컬럼비아호 (32).** 통행료 면에서는 일반 특수 땅입니다 (가격 45만, 통행료 40만). 우주여행 요금을 받는 땅이기도 합니다.

## 7. 건물과 통행료

건물: **별장**, **빌딩**, **호텔**. 특수 땅(제주도, 콩코드, 부산, 퀸 엘리자베스, 컬럼비아, 서울)에는 건물을 지을 수 없습니다.

적용하는 규칙 (DOS 테이블 기준):
- 도시 하나에 별장, 빌딩, 호텔을 **종류별로 최대 2개씩** 지을 수 있습니다 (DOS 코드와 Java 이식판이 같음).
- 통행료 = 지어진 건물 각각의 통행료를 모두 더한 금액입니다 (예: 빌딩 2개 + 호텔 1개 = 빌딩 통행료×2 + 호텔 통행료). 건물이 하나도 없을 때만 대지료입니다. 아래 표는 건물 1개당 금액입니다.
- 건축비는 같은 그룹의 모든 도시가 같습니다.
- 건물을 은행에 팔면 건축비를 돌려받습니다.
- 땅을 은행에 팔면 땅값과 건물 건축비를 돌려받습니다 (반액대매출 카드는 절반).
- 같은 색 그룹을 모두 가져도 보너스는 없습니다. 실제 게임에 없는 규칙입니다.

## 9. 파산과 승리

1. 낼 돈이 모자라면 먼저 건물을, 다음에 땅을 7절의 가격으로 은행에 팝니다. **Apple II 버전에서 컴퓨터 플레이어는 이 매각을 자동으로 합니다**: 돈이 찰 때까지 건물을 하나씩 팔고(번호가 낮은 칸부터, 비싼 종류부터), 건물이 없으면 가장 싼 땅부터 팝니다. **사용자는 자동으로 팔리지 않습니다.** 돈이 모자라면 매각 메뉴가 열려 돈이 찰 때까지 직접 팔 물건(건물은 건축비, 땅은 땅값)을 고르며, 아무것도 팔 것이 없으면 파산합니다. 사용자는 자기 차례에 3번 키로 언제든 미리 팔 수도 있습니다. (황금열쇠 '반값 매각' 카드만은 카드가 정한 대로 가장 비싼 땅을 반값에 자동으로 팝니다.)
2. 그래도 못 내면 파산입니다. 게임에서 빠지고, 남은 현금은 돈을 받을 사람(은행이면 없어짐)에게 가고, 땅은 주인 없는 상태로 은행에 돌아가며 (건물 제거), 보유 카드는 덱으로 돌아갑니다. *(위키에는 지불 불능이면 교육 칸에서 2번 쉰다고 되어 있으나 이는 어린이판 규칙이라 쓰지 않습니다.)*
3. **승리:** 마지막까지 남은 플레이어.
4. **선택 종료:** 시작할 때 정한 라운드 수가 끝나면 가장 부유한 플레이어 승리 (현금 + 모든 땅과 건물의 판매 가치). 블로그의 "자산 최다" 규칙입니다. Apple II 버전은 이를 옵션으로 제공합니다.

## 10. Apple II 버전의 단순화

| 실제 규칙 | Apple II |
|---|---|
| 모두 거절하면 경매 | 뺌 |
| 플레이어 간 거래 | 불가 (실제 게임도 불가) |
| 대출 | 없음 |
| 5번 카드 상금을 다른 플레이어가 정함 | 1만 고정 |
| 빚을 질 때 팔 물건을 직접 고름 | 사용자는 직접 고름, 컴퓨터는 자동 매각 (9절) |
| 무인도 탈출 카드를 다른 플레이어에게 판매 | 불가 (사용만 가능) |
| 건물 수량 한정 | 무제한 |
| 지폐로 현금 관리 | 숫자 하나, 지폐는 그림 |

## 11. Apple II 버전의 화면 표현

- **보드:** 항상 화면에 있음. 칸에는 줄인 이름, 칸 테두리에 소유자 색, 칸에 건물 아이콘.
- **팝업(대화창):** 주사위, 증서 카드, 황금열쇠 카드, 지폐(돈), 플레이어 정보.
- **돈:** 지폐 7종은 비트맵 7개가 아니라, 금액 글자와 색 띠만 다른 상자 템플릿 하나.
- **카드:** 제목과 본문을 텍스트 테이블에서 가져오는 상자 템플릿 하나.
